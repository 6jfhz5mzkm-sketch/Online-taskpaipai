# 管理后台视觉规范(截图解读,供前端 Agent 遵循)

> 来源:用户提供的 3 张设计规范截图(设计基础/组件规范/工作台)。本文件为视觉真源,前端 Agent 遵循。

## 一、设计基础(Design Standards)

### 1. 颜色
- **品牌色/主色**:蓝色 `#2C8FF5`(严谨专业感)
- **辅助色**(同色调,增活力):`#FF4D4F`(红)、`#FFA914`(橙)、`#52C41A`(绿)、`#18C989`(青绿)
- **文字/其他**:`#2A364D`(深蓝黑,标题)、`#535F70`(次级)、`#909AB2`(弱)、`#E5E8C7`(背景/浅)

### 2. 字体
- 中文:苹方(系统无则 fallback 系统字体);英文:DIN(数字/强调用)
- 字号标准:18px(特殊标题/指标数字)、16px(模块标题/重要内容)、14px(正文内容)、12px(次要内容)

### 3. 布局
- 顶部菜单 + 左侧边栏 + 内容区
- **8px 倍数原则**:尺寸与间隔遵循 8px 倍数
- 栅格:COLUMN=80PX,GUTTER=16PX,ROW=12 列

## 二、组件规范(Component Standards)

### 组件(Element Plus 风格,按截图):
- **Button**:主按钮(实心蓝)、次按钮(浅色/描边)、幽灵按钮
- **Icon**:彩色业务图标(公司/职位/数据屏等)+ 线性功能图标
- **Space 间距**:统一 8px 倍数
- **Divider 分割线**:细分隔线
- **Switch 开关**:ON 蓝 / OFF 灰
- **Tag 标签**:多色彩(蓝/青绿/橙/红/绿/紫等状态色)
- **Tooltip 提示**:黑色气泡
- **Feedback 反馈**:成功(绿)/信息(蓝)/警告(橙)/错误(红) 四色示例条
- **Progress 进度条**:蓝/绿/红/灰 多色,含 0% / 66% / waiting 态
- **Input 输入框**:默认/输入/错误(红边框+红提示)/禁用
- **File 文件图标**:按类型彩色(图片/文档/视频/音频/压缩/表格/演示/文本/未知)

## 三、工作台(Workbench)布局
- **顶部**:欢迎语(早上好,Daisy!)+ 关键数字卡片(今日工作流/活跃等)
- **数据卡片**:彩色数字卡片(可点击,如 10,000 中心)
- **快捷入口**:图标+文字网格(员工概况/快捷入口/日程待办/审批概况/新增资产/今日考勤)
- **图表区**:柱状图/饼图/趋势图(业务数据可视化)
- **布局原则**:集成常用功能入口、实时信息展示、任务管理;按人眼视觉动线放置模块;突出重要功能入口

## 四、图标策略(用户要求:一套在商家端+管理后台通用)
- **结论**:采用 **iconfont(阿里巴巴矢量图标库)** 统一方案——能力最匹配截图那种"彩色业务图标",且一套 SVG/字体可在 uni-app 商家端 + Vue3 管理后台两端引用。
- 落地:挑选/上传彩色业务图标(公司/职位/文件/数据屏等)+ 线性功能图标,iconfont 生成字体/SVG 文件;两端各自封装组件引用同一套图标名。
- 若缺 iconfont 权限,可用开源线性 SVG 集(Phosphor/Lucide)做功能图标,彩色业务图标单独处理。
