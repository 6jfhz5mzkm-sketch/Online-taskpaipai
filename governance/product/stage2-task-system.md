### T2.1.2 查询商标注册号

**功能说明：**
- 输入品牌名 → 返回商标注册号列表
- 支持模糊搜索及自动弹出相关提示
- 数据来源：系统维护的品牌映射表

**跳转链接：** 京麦首页-店铺-品牌管理

**商标注册号数据：**
- 数据来源文件：品牌注册号清单【8月5日】.xlsx
- 数据量：139个品牌（含重复品牌不同注册号）
- 数据格式：品牌名称 + 申请/注册号

**示例数据：**
| 品牌名称 | 申请/注册号 |
|---------|------------|
| 浪琴 | 318347 |
| 天梭 | 7603179 |
| 帝陀 | 52077239 |
| 劳力士 | 164949 |
| 欧米茄 | 3181098 |
| 小米 | 10674581 / 10979463 |
| 华为 | 36726408 |
| 苹果 | 14570573 |
| 三星 | 8494296 / 770224 |
| ... | ... |

**预留接口：**
- 后端API：GET /api/trademark/search?keyword=小米
- 返回格式：[{ brand_name: "小米", registration_number: "10674581" }, ...]
- 支持模糊搜索：输入"小"可返回"小米"、"小天鹅"、"小熊"等
- 自动提示：输入时实时返回匹配结果

**数据库表设计：**
`sql
CREATE TABLE trademark_registry (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  brand_name VARCHAR(128) NOT NULL COMMENT '品牌名称',
  registration_number VARCHAR(64) NOT NULL COMMENT '申请/注册号',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_brand_number (brand_name, registration_number)
);
`

**任务管理后台维护入口：**
- 需要在管理后台预留商标注册号维护功能
- 支持：新增、编辑、删除、批量导入
- 数据来源：品牌注册号清单.xlsx

**完成标准：** 查询到商标注册号

### T2.2.4 填写商品属性

**引导内容：**

属性分类：
- 必填属性（按商品实际情况填写，标题中有体现的属性需与标题保持一致）
- 重要属性（完整准确填写有助于商品获得更多曝光机会）
- 其他属性（有利于商品精细化运营，为消费者展示更全面的商品信息）

以二手手机类目为例：

**必填属性：**
- 来源渠道（如：官方正品、资源机、官翻机等）
- 机型（如：iPhone 15 Pro Max）
- 系统（如：iOS）
- 后摄主像素（如：4800万）
- 电池容量（如：4422mAh）
- 充电功率（如：27W）
- 无线充电（如：支持）

**重要属性：**
- CPU型号（如：A17 Pro）
- 屏幕材质（如：OLED）
- 屏幕特色（如：全面屏、高刷新率）
- 生物识别（如：面容ID）
- 风格（如：商务、简约）
- 三防标准（如：IP68）
- 电池可拆卸（如：不可拆卸）
- 拍照特色（如：夜景模式、人像模式）
- 适用人群（如：商务人士、学生）
- 卫星网络（如：支持）
- 独立Hi-Fi芯片（如：无）

**其他属性：**
- 屏幕外观（如：直面屏）
- 前摄主像素（如：1200万）
- CCC强制性认证（如：是）
- SIM卡类型（如：Nano SIM）
- 双卡机类型（如：双卡双待）
- 电信设备进网许可证（如：有）
- SIM卡数量（如：2个）
- AI商品分类（如：手机）
- 屏幕尺寸（如：6.7英寸）
- 屏幕分辨率（如：2796x1290）
- 充电接口（如：Lightning）
- 5G网络（如：支持）

商品属性填写指南（左侧固定面板）：
- 必填属性：红色带"*"属性如未填写，将无法成功上架销售商品
- 重要属性：用户在意、推荐各项高星场景高关注度的属性
- 其他属性：有利于商品精细化运营

⚠️ 重要提示：
- 必填属性必须填写，否则无法上架
- 重要属性完整填写有助于商品获得更多曝光机会
- 标题中有体现的属性需与标题保持一致

**完成标准：** 点击"已完成"

### T2.2.5 上传商品图片

**引导内容：**

主图模式选择：
- 一套主图模式：
  - 保留SPU主图，所有销售属性无需再上传SKU主图
  - 适用场景：大多数商品、单一销售属性
- 多套主图模式：
  - 取消SPU主图，需在每个销售属性处上传一套SKU主图
  - 适用场景：销售属性差异大的情况

主图规格要求：
- 方主图必填至少一张
- 部分类目可开启长图开关上传3:4比例长图
- 主图视频商家可自主选择维护
- 图片支持电脑本地上传或图片空间选择
- 支持在线裁剪、AI做图
- 最多上传10张

1:1主图规格：
- 宽高比例1:1
- 宽高均大于480px
- 推荐尺寸1440×1440
- 建议大小≤3MB
- 格式：JPG/PNG/JPEG

⚠️ 重要提示：
- 一套主图=不必每SKU上传；多套主图=每个SKU都要上传
- 只有SKU主图在前台展示，SPU主图不展示
- 使用主图打标功能制作的营销信息不算作营销面积
- 右上角「图片前台预览」可实时查看前端展示效果

**完成标准：** 点击"已完成"

### T2.3.3 优化商品信息健康分

**跳转链接：** https://wares-jdm.jd.com/ware/commodity-inspection

**引导内容：**

信息分定义：通过全、准、好三个维度评估

分数范围：0-100分

分数等级：
- 50-59分：存在违规
- 60-77分：合格
- 78-90分：良好
- 91-100分：优秀

6大类考核因子：
- 图片有无：素材图、长图、主图张数≥5张、搜索主图
- 图片质量：搜索主图优质、优质主图、营销区域面积≤35%
- 文本类：短标题、通用卖点（3个满分）、重要属性、必填属性
- 视频类：主图视频
- 其他：使用说明书、尺码助手、官方验
- 违规因子：类目违规、属性违规、品牌违规、主图违规、标题违规

对流量的影响：
- 信息分每提升一分，单品搜索曝光提升1.3113个UV
- 90-95分档的平均搜索曝光是78-90分档的2倍
- 96-100分档的平均搜索曝光效果最佳
- 信息分越高、商品星级越高
- 信息分越高、店铺星级越高
- 新品报名卡70分及以上
- 新品打标卡75分及以上
- 中小商成长任务维护90分以上

分数更新：T+1更新，部分因子实时更新

**完成标准：** 点击"已完成"
