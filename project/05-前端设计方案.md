## 一、产品定位

本项目包含两个独立前端应用，共享同一套后端 API：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌───────────────────┐        ┌───────────────────┐    │
│  │  H5 任务中心       │        │  PC 管理后台       │    │
│  │  (商家端)          │        │  (运营端)          │    │
│  │                   │        │                   │    │
│  │  受众: 拍拍商家     │        │  受众: 平台运营人员  │    │
│  │  场景: 移动端H5     │        │  场景: PC浏览器     │    │
│  │  核心: 查看/完成任务 │        │  核心: 配置/管理任务 │    │
│  └─────────┬─────────┘        └─────────┬─────────┘    │
│            │                            │               │
│            └──────────┬─────────────────┘               │
│                       ▼                                 │
│            ┌─────────────────────┐                      │
│            │   后端 API 服务      │                      │
│            │   localhost:3000     │                      │
│            └─────────────────────┘                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 维度 | H5 任务中心 | PC 管理后台 |
|------|------------|------------|
| 用户 | 拍拍二手 POP 商家（约 200 家） | 平台运营人员（1-3 人） |
| 设备 | 手机浏览器 / 飞书内置浏览器 | PC 浏览器 |
| 分辨率 | 375px ~ 428px（移动端） | 1280px+（桌面端） |
| 核心目标 | 引导商家完成入驻任务 | 配置任务、查看进度、管理数据 |
| 访问方式 | 飞书推送链接 / 商家后台跳转 | 独立 URL，账号密码登录 |

```
└─────────────────────────────────────┘
```

**交互规则：**

| 行为 | 说明 |
|------|------|
| 默认展开 | 当前进行中的阶段自动展开 |
| 已完成阶段 | 默认折叠，点击可展开查看 |
| 未开始阶段 | 显示锁定状态，不可操作 |
| 点击「去完成」 | 跳转到任务详情页 |
| 下拉刷新 | 重新拉取任务列表 |
| 进度条颜色 | 已完成=绿色，进行中=蓝色，未开始=灰色 |

**数据来源：**

```
GET /api/task/stages
Authorization: Bearer <token>

响应: {
  code: 0,
  data: [
    {
      id, stageId, stageNum, title, description, status,
      firstLevelTasks: [
        {
          id, taskId, stageId, title, description, buttonText, status, sortOrder,
          secondLevelTasks: [
            { id, taskId, title, description, detail, type, completionType, actionText, actionUrl, tag, defaultCompleted, status }
          ]
        }
      ]
    }
  ]
}
```

**进度计算逻辑（前端）：**

```typescript
function calcProgress(stages: Stage[]) {
  let totalTasks = 0
  let completedTasks = 0

  for (const stage of stages) {
    for (const group of stage.firstLevelTasks || []) {
      for (const task of group.secondLevelTasks || []) {
        totalTasks++
        if (task.completed) completedTasks++
      }
    }
  }

  return totalTasks === 0 ? 0 : Math.round((completedTasks / totalTasks) * 100)
}
```

> 注意：当前后端没有返回每个任务的完成状态（merchant_task_progress 表为空）。
> V1 阶段可以先用 `defaultCompleted` 字段模拟，或前端本地存储已完成状态。

**登录流程：**

```
1. 商家点击「使用飞书账号登录」
2. 跳转飞书 OAuth 授权页
3. 授权后飞书回调，携带 code 参数
4. 前端将 code 发送到 POST /api/auth/feishu/callback
5. 后端返回 JWT token
6. 前端存储 token 到 localStorage
7. 跳转首页
```

> V1 阶段使用 Mock 模式，前端提供一个「开发者登录」按钮，直接获取 mock token。

## 四、API 对接层设计

### 4.1 Axios 实例配置

```typescript
// 两个应用共享相同的 axios 配置模式

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE,  // 'http://localhost:3000'
  timeout: 10000,
})

// 请求拦截器：自动携带 JWT Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一错误处理
api.interceptors.response.use(
  (res) => {
    if (res.data.code !== 0) {
      // 业务错误
      Toast.fail(res.data.message)
      return Promise.reject(res.data)
    }
    return res.data.data
  },
  (err) => {
    if (err.response?.status === 401) {
      // Token 过期，跳转登录
      localStorage.removeItem('token')
      router.push('/login')
    }
    return Promise.reject(err)
  }
)
```
